## 📌 Featured Projects

### [🛒 Cartlify – E-commerce Backend API](https://github.com/MaksymDziubanchuk/Cartlify)

Production-style e-commerce backend API built with Fastify, TypeScript, PostgreSQL and Prisma.

- Fastify + TypeScript + PostgreSQL + Prisma backend API
- 58 documented OpenAPI operations across auth, users, products, categories, orders, payments, favorites, reviews, chat, admin, root and system modules
- JWT access tokens and refresh token rotation via HttpOnly cookies
- Role-based access control for USER, ADMIN and ROOT roles
- PostgreSQL RLS baseline with role/schema scripts and migrations
- Redis integration for cache and readiness infrastructure
- OAuth flows with Google, GitHub and LinkedIn
- Cloudinary uploads for avatars and product images
- SendGrid email verification and password reset flows
- Stripe checkout session and webhook module
- WebSocket chat module with guest, user, bot and admin support flows, including current thread, admin queues, message history and thread closing
- Admin dashboard statistics endpoint
- Swagger/OpenAPI documentation with tags, security schemes, operation IDs, response descriptions and DTO-based examples
- GitHub Actions workflows for project automation and validation scripts
- Deployed to Railway

🔗 [API Docs](https://cartlify.up.railway.app/documentation/)  
🔗 [Repository](https://github.com/MaksymDziubanchuk/Cartlify)
