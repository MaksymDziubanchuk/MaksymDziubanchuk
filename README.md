- MongoDB & Mongoose  
- File uploads with Cloudinary

- API docs via Swagger

🔗 [Live Site](https://petly-project.vercel.app/)

### [🛒 Cartlify – E-commerce Backend API](https://github.com/MaksymDziubanchuk/Cartlify)

- Fastify + PostgreSQL + Prisma backend API  
- 51 REST endpoints across auth, users, products, categories, orders, favorites, reviews, admin, and system modules  
- JWT access tokens + refresh token rotation via HttpOnly cookies  
- RBAC route guards, PostgreSQL RLS baseline, roles/schemas scripts and migrations  
- Cloudinary uploads and SendGrid email flows  
- Deployed to Railway
